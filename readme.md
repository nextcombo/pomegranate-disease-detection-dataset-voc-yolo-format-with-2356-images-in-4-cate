# Pomegranate Disease Detection Dataset VOC+YOLO format with 2356 images in 4 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 2356

Number of annotations (number of xml files): 2356

Number of annotations (number of txt files): 2356

Labeling category count: 4

Label category names (note that the order of yolo format categories does not correspond to this, but is based on the labels folder's classes.txt): ["Alternaria", "Anthracnose", "Bacterial_Blight", "Cercospora"]

Number of boxes labeled in each category:

Alternaria frame count = 1437

Anthracnose frame count = 111

Bacterial_Blight frame count = 225

Cercospora frame count = 650

Total frame count: 2423

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: No

Special : This dataset does not guarantee the accuracy or precision of the trained models or weight files. The dataset is provided with accurate and reasonable annotations only.
